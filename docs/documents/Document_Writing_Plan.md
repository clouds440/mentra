# Document writing · planned

**Status:** planned; not available in the current product. Added to the product roadmap on 30 October 2026.

Mentra is planned to help users write documents such as PDF, DOCX and TXT files.
This is distinct from today's document reading, source ingestion and assessment
question-paper export. Those existing capabilities do not constitute a general
document-writing editor or workflow.

| Planned capability | Intended outcome | Status |
| --- | --- | --- |
| Document drafting | Turn a request or outline into a structured document | Planned |
| PDF output | Produce a shareable, laid-out document | Planned |
| Word / DOCX output | Produce a document that can be edited in a word processor | Planned |
| Plain text / TXT output | Produce a portable text document | Planned |
| Additional formats | Extend output formats as the implementation develops | To be decided |

## Design work still required

| Area | Decision to make before implementation |
| --- | --- |
| Editing experience | How drafting, revisions, preview and downloads fit into the workspace |
| Source grounding | How user-selected Library sources and citations carry into generated documents |
| Ownership and storage | How drafts, export versions and original files use existing account and Files boundaries |
| Format fidelity | How layout, typography, equations and multilingual content are checked in each supported export |
| Recovery | How partially completed generation and export failures can be resumed without losing edits |

No release date or final implementation contract is established by this note.
See [Documents](README.md) for current extraction capabilities and
[Files](../files/README.md) for existing private storage/delivery contracts.
